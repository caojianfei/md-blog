# 管理后台样式与交互优化计划

## 1. 目标与概述
将当前单文件（`App.vue`）的后台管理重构为基于 `vue-router` 的多页面应用，优化 UI/UX 体验，使其交互更友好，同时保持轻量、简洁的整体风格一致性。解决目前表单操作与列表页面混杂的问题。

## 2. 现状分析
- **架构问题**：所有页面（登录、工作台、列表、编辑器、设置）全写在 `App.vue` 中，通过 `v-if` 切换，导致文件过长，逻辑耦合严重。
- **交互问题**：
  - 文章编辑器（复杂表单）直接出现在文章列表下方，操作体验拥挤。
  - 分类、标签（简单表单）采用列表上方的内联输入框形式，不够规范。
- **样式问题**：`base.css` 提供了基础样式，但缺乏弹窗（Modal）支持，且交互反馈（如 hover 态、过渡动画）可以进一步提升。

## 3. 详细改造方案

### 3.1 路由与架构拆分 (Vue Router)
- **启用 `vue-router`**：在 `src/router/index.js` 中配置路由。
- **重构 `App.vue`**：仅保留 `<router-view>` 作为路由出口。
- **抽离基础布局**：创建 `src/components/Layout.vue`，包含侧边栏（Sidebar）和顶部/主内容区域。

### 3.2 页面拆分与表单隔离
将业务逻辑拆分到 `src/views/` 目录下：
- **`Login.vue`**：独立的登录页面。
- **`Dashboard.vue`**：工作台数据展示。
- **`ArticleList.vue`**：文章列表页。移除内联编辑器，新建/编辑按钮改为跳转到独立页面。
- **`ArticleEdit.vue`**（复杂表单）：独立的文章编辑页面，提供更宽广的写作和设置空间。
- **`CategoryList.vue` & `TagList.vue`**：分类和标签管理。移除内联输入框，改为点击“新建”或“编辑”按钮后，弹出 Modal 进行操作。
- **`Settings.vue`**：站点设置页面。

### 3.3 抽取通用组件
- **`Modal.vue`**：新建一个通用弹窗组件，包含遮罩层（Overlay）、标题、内容区、底部操作栏（取消/确认），并支持简单的显示/隐藏过渡动画。

### 3.4 样式与交互优化 (`src/styles/base.css`)
- **保持风格**：不引入庞大的第三方 UI 库，继续使用并优化现有原生 CSS 变量系统，确保亮/暗色模式完美兼容。
- **增加 Modal 样式**：实现居中弹窗及半透明背景遮罩（`.modal-overlay`, `.modal-content`）。
- **增强交互反馈**：
  - 为所有按钮 (`.btn`)、输入框 (`.input`, `.textarea`, `.select`) 增加 `transition: all 0.2s`。
  - 增加按钮悬停 (`:hover`) 提亮/变暗效果，增加输入框聚焦 (`:focus`) 时的边框高亮或阴影效果。
  - 确保所有可点击元素都具备 `cursor: pointer`。

## 4. 实施步骤与 TODO
1. 创建 `src/router/index.js` 并配置路由。
2. 提取 `Layout.vue` 与 `Modal.vue` 组件。
3. 将 `App.vue` 中的逻辑拆分到各个 View 页面中（Dashboard, Articles, Categories, Tags, Settings, Login）。
4. 在 Categories 和 Tags 页面接入 `Modal.vue` 实现表单弹窗。
5. 在 Articles 列表页面修改按钮跳转逻辑，实现 `ArticleEdit.vue` 独立页面。
6. 完善 `base.css` 中的弹窗样式和交互过渡动画。
7. 调整 `main.js` 注册路由。

## 5. 验证与验收
- 启动 `npm run dev` 访问后台。
- 验证所有页面路由跳转是否正常（包含登录拦截）。
- 验证“文章新建/编辑”是否在独立页面打开，且保存正常。
- 验证“标签/分类”是否通过弹窗进行新增和修改，且不再与列表混在一起。
- 验证深色/浅色主题切换及按钮 Hover 等交互动画是否流畅。
